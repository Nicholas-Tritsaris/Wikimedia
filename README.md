# WikiBlueboop

A Wikipedia-like page with the "blueboop" theme.

## How it works
This is a static site that renders MediaWiki markdown (Wikitext) on the fly.
Articles are stored in the `content/` directory as `.mw` files.

## Adding Content
1. Create a new `.mw` file in the `content/` folder (e.g., `My_Article.mw`).
2. Use Wikitext syntax for formatting.
3. Access the article via `index.html#/My_Article`.
